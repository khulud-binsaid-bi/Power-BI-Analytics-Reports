# Power BI Analytics & Dashboards Portfolio
Power BI reports and dashboards created during training at Modeem Digital Association

مجموعة من التقارير التحليلية ولوحات المعلومات التفاعلية التي أعددتُها باستخدام **Power BI** خلال فترة التدريب في **جمعية مديم الرقمية**.

## التقارير المرفقة:
1. **تقرير تحليل وجاهزية الجمعيات المهتمة بمسرعة رقيم:** تحليل التوزيع الجغرافي والقطاعي والجهات المشرفة، وقياس جاهزية واكتمال بيانات التواصل.
2. **تقرير المؤشرات الإحصائية لبيانات الجمعيات المهتمة ببرنامج المسرعة:** استعراض التوزيع الجغرافي، جهات الإشراف، توفر المسؤول التقني، ومدى اكتمال قنوات التواصل.
3. **تقرير ترشيح الجمعيات للمسرعة السادسة:** تصنيف الجمعيات حسب أولويات الترشيح، متوسط درجة التحول الرقمي، التوزيع الجغرافي، والاستنتاجات والتوصيات لدعم اتخاذ القرار.
4. **التقرير الختامي لمشاريع المسرعات الرقمية - جمعية مديم:** مقارنة متوسط نضج التحول الرقمي والجاهزية قبل وبعد البرنامج عبر الجهات المستفيدة.
